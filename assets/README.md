# 🎬 Odhikar Media & Demo Video Assets

Store app video walkthroughs, screenshots, and visual demos here.

### Adding your Video:
1. Save your screen recording or demo as `demo_video.mp4` in this `assets/` folder.
2. The root `README.md` is configured with an HTML5 `<video>` tag referencing `assets/demo_video.mp4` with `assets/preview.png` as the poster thumbnail.
3. If hosting externally (e.g. YouTube, Google Drive, Loom, Vimeo), update the video link or badge in [`README.md`](../README.md).
